# BarCarila 日本BAR希少度 v1.7 addendum

Status: PROVISIONAL
Date: 2026-09-04
Scope: v1.6の代表75杯から100杯へ拡張する次の25杯。ラム/テキーラ/ブランデー、ビール・ワインベース、日本由来・日本で定着したカクテルを中心に選定。
Runtime policy: `japan_rarity_score = 100 - japan_availability_score`。世界的知名度ではなく、日本国内の一般的なBARで実際に注文成立しやすいかを優先する。

## 評価方針

既存v1系の重みを継続する。

- 45%: 日本国内の現行BAR/ホテルBAR等の実メニュー提供確認
- 25%: 国内での材料・ブランド流通、材料の一般性
- 20%: 日本のバーテンダー文化・スタンダード性
- 10%: オペレーション容易性

単一店舗への掲載だけで全国的な定番とは判定しない。海外で有名でも、日本の一般BARで材料・技法・注文認知に制約があればavailabilityを下げる。

『カクテル完全バイブル』（渡邉一也監修）は日本側のカクテル体系・材料構成を見る補助資料として扱う。単なる掲載は高availabilityの根拠にせず、現行日本BARメニューを優先する。

## v1.7での判断

v1.7は「有名クラシックを増やす」だけではなく、日本で実際に注文成立しやすい層と、知名度はあっても一般BARでは成立しにくい層を同時に追加した。

特に `ソルクバーノ / ボストンクーラー / マタドール / ワインクーラー / パナシェ` は、世界的知名度だけを見ると目立たない一方、日本の現行メニューでは複数確認でき、BarCarilaの目的に合う。

一方 `ゾンビ / ダークアンドストーミー / プランターズパンチ / ミリオンダラー / ミチェラーダ` は、実在・現役であることは確認できるが、材料・技法・業態依存が強いため希少度を高めに維持する。
