# BarCarila 日本BAR希少度 キャリブレーション追補 v1.3

Status: PROVISIONAL
Date: 2026-09-04

## 目的

v1.2で重点確認した希少度30〜55%付近の中間帯をさらに補正し、D1酒マスターへ移行できる粒度まで評価ルールを整理する。

## 追加確認と補正

### アメリカーノ

一般BARの現行メニューで、ネグローニ、オールドファッションド、ギムレット等と並んで掲載されている実例を確認。材料もカンパリ、スイートベルモット、ソーダで、通常のBAR設備・仕入れで成立しやすい。

旧 v1.1: Availability 38 / Rarity 62
v1.2: Availability 60 / Rarity 40
v1.3 provisional: Availability 62 / Rarity 38 / やや珍しい / Confidence 0.86

「名前を見かける頻度」と「実際に作れる可能性」を分けると、極端に希少側へ置く根拠は弱い。

### ミントジュレップ

国内BAR向けコンテンツおよび複数店舗で提供例あり。生ミント常備が制約になるが、専門店だけの酒とは言えない。季節性・生鮮材料依存を反映し、定番帯までは上げない。

v1.3 provisional: Availability 58 / Rarity 42 / やや珍しい / Confidence 0.86

### グラスホッパー

国内のカクテルバー/一般BARの実メニューで確認できる。材料はグリーンミントリキュール、カカオリキュール、生クリーム等で、全店常備ではないが専門設備を必要としない。

v1.3 provisional: Availability 60 / Rarity 40 / やや珍しい / Confidence 0.85

### ロングアイランドアイスティー

材料点数は多いが、一般ショットバーでの実提供例があり、名称認知も高い。材料数だけを理由に希少側へ寄せすぎない。

v1.3 provisional: Availability 58 / Rarity 42 / やや珍しい / Confidence 0.85

### フレンチ75

日本国内でも現行メニュー掲載を確認できる一方、シャンパン/スパークリングワイン常備店に寄りやすい。一般ショットバー全体ではジン系定番ほど普遍的ではない。

v1.3 provisional: Availability 64 / Rarity 36 / やや珍しい / Confidence 0.84

### カイピリーニャ

フレッシュフルーツ系BARや一般ショットバーで提供例を確認できる。一方、カシャッサ常備が前提となるため、材料の一般性はジン/ウォッカ系より明確に低い。

旧 v1.1: Availability 47 / Rarity 53
v1.3 provisional: Availability 50 / Rarity 50 / 珍しい / Confidence 0.80

### コープスリバイバー No.2

国内の専門性の高いカクテルバーで現行提供を確認。存在自体は現役だが、一般BARの標準注文として扱うには専門性・材料依存が大きい。

v1.3 provisional: Availability 34 / Rarity 66 / 珍しい / Confidence 0.78

### ピスコサワー

日本国内で提供例は存在するが、ペルー料理店・南米系業態など専門文脈に寄る。一般BARでのピスコ常備が主要制約。

v1.3 provisional: Availability 38 / Rarity 62 / 珍しい / Confidence 0.78

## アペロールスプリッツの扱い

日本向け公式サイトが存在し、国内流通そのものは十分。作成もアペロール、プロセッコ、ソーダという単純な構成で難しくない。

ただし、日本の一般的なBARで「名称注文すれば高確率で出る」水準とまでは確認できず、イタリアン、ホテル、アペリティーヴォ文脈に偏る。

したがって世界基準の「定番」は採用しない一方、過度に希少側にも置かない。

v1.3 provisional: Availability 60 / Rarity 40 / やや珍しい / Confidence 0.86

## BAR-NAVIの扱いに関する補正

BAR-NAVIは有力な実店舗証拠だが、掲載対象にはサントリー製品の取扱条件等があるため、日本全国のBAR全体を無作為抽出した母集団ではない。

そのため以下のように扱う。

- 個別店舗の現行メニュー掲載: 強い実提供証拠
- 複数店舗・複数地域での掲載: 普遍性を示す補助証拠
- 検索ヒット件数そのもの: 弱い補助証拠
- 0件: 「日本で提供されない」の証拠にはしない

## v1.3時点の重要原則

希少度は「名前が有名か」ではなく「日本の一般BARで実際に成立するか」を評価する。

成立可能性は最低でも次を分けて考える。

1. バーテンダーが知っている可能性
2. 材料が店にある可能性
3. 技法・設備上その場で作れる可能性
4. 日本のBARで実際に名称注文され/提供されている実績

この4つが揃うほど Availability を上げる。

## 次工程への判定

代表50杯はまだ完全な統計値ではないが、D1実装に必要なデータモデルを決めるには十分な差異が確認できた。

したがって、調査を止めるのではなく並行継続しつつ、次工程としてD1酒マスター設計へ進む。

評価値は `evidence_version` と `evaluated_at` を持たせ、後から再評価・更新可能にする。これにより最初から完全な100杯/400杯データを作り切る必要はない。
