# BarCarila 日本BAR希少度 実装ステータス

Date: 2026-09-04

## CONFIRMED

- BarCarilaの希少度は世界的知名度ではなく、日本国内の一般BARで実際に注文できる可能性の低さを表す。
- バーテンダーCarilaは全世界の酒文化を扱い、日本希少度で候補を制限しない。
- 希少度は毎回Web検索せず、調査済み値をD1へ保存して参照する。
- 酒の固定/準固定説明文もD1へ保存し、会話依存の推薦理由のみLLMで生成する方向とする。
- ユーザー提供『カクテル完全バイブル』は日本側の専門・教育文脈を示す補助資料として使うが、掲載=定番とは扱わない。
- 既存 `drink_images` のD1運用を壊さず、酒マスターを追加する。
