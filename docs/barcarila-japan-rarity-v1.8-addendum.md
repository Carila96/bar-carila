## 今回の調査方法

- 『カクテル完全バイブル』のカクテルインデックスを母集団として使用する。掲載のみでは日本BAR availability の根拠にしない。
- 既存100杯で定めた4軸（現行日本メニュー45%、国内材料流通25%、日本側スタンダード性20%、オペレーション10%）を維持する。
- 複数杯を同時に調査できる現行BARの広いメニューを優先して一次判定する。
- 特殊材料、卵、乳製品、高度数ラム、シェリー、シャルトリューズ等が絡む境界例は個別に追加確認する。
- 証拠が弱いものは confidence を下げ、無理に高精度扱いしない。
- `japan_rarity_score = 100 - japan_availability_score` を維持する。

## 精度確認

今回の50杯は、単なるレシピ本掲載だけで点数を付けていない。現行日本BARメニューで複数確認できるものは availability を上げ、特殊材料・特殊オペレーション・一般メニュー密度の低さがあるものは下げた。

特に以下は境界確認に使える。
- ウォッカトニック / ジンライム / ブルドッグ: 一般BARでも成立しやすい側。
- アラスカ / グリーンアラスカ: 同系統でもシャルトリューズと一般メニュー密度で差を付けた。
- ブラッディシーザー: レシピ自体は単純でもクラマト常備が制約。
- ジャックター: 現行提供例はあるが高度数ラムが制約。
- ブランデースマッシュ / ブランデーエッグノッグ: 古典レシピ掲載だけで availability を上げず、現行提供密度とオペレーション制約を重視。
- アメリカンレモネード / ドッグズノーズ / ビアスプリッツァー: クラシック性より国内実メニューと材料容易性を重視。
