# BarCarila 日本BAR希少度 キャリブレーション追補 v1.5

Status: PROVISIONAL
Date: 2026-09-04

## 目的

v1.4までの中間帯補正に続き、代表50杯のうちConfidenceが低かった後半群を重点確認する。日本国内の現行BAR/ホテルBAR/ダイニングBAR等の実メニューを中心に、専門書の標準性と材料・技法制約を分離して再評価する。

## 書籍資料の扱いの再確認

ユーザー提供『カクテル完全バイブル』は約400種を収録するため、単純掲載は「日本の一般BARで注文しやすい」の証拠にはしない。

一方で、同書は第2章に「スタンダード・カクテル24」、第3章に「3+1本で作るカクテル50」を独立項目として設けている。前者は日本向け専門・教育文脈での標準性、後者はベース酒・副材料の汎用性を測る補助証拠として扱う。

## 今回の追加確認

### パローマ

東京のホテルBAR、ホテル系BAR、ダイニングBAR、カフェバーなど複数業態で現行提供を確認。テキーラ、グレープフルーツ、ソーダという構成も一般BARで技術的には成立しやすい。

世界的知名度だけで評価するのは避けるが、日本で「かなり店を選ぶ」とする旧評価も低すぎる。

v1.5 provisional: Availability 64 / Rarity 36 / やや珍しい / Confidence 0.86

### ブロンクス

現行の国内BARメニューでクラシック群の一つとして提供例を確認。ジン、ベルモット、オレンジジュース系で、特殊器具や特殊仕込みは不要。

現代日本での名称注文頻度は高くない一方、材料・技法上は作れる店が比較的多いと考える。

v1.5 provisional: Availability 62 / Rarity 38 / やや珍しい / Confidence 0.82

### マイタイ

現行の国内BARで通常カクテル/クラシック枠として提供例を複数確認。旧評価より「実提供されている」側へ補正する。

ただしレシピ差が大きく、オルジェー、ココナッツ、複数ラム、各種ジュースなど店のスタイルに依存するため、一般BAR成立率を定番帯までは上げない。

v1.5 provisional: Availability 55 / Rarity 45 / やや珍しい / Confidence 0.84

### ピニャコラーダ

北海道のBAR、フルーツカクテルBAR、ホテルBAR等で提供例を確認。国内BAR運営者の資料でもクラシックとして扱われる例がある。

一方、ココナッツクリーム/ミルク、パイナップル、場合によってはブレンダーやフローズン提供など材料・スタイル制約が残る。

v1.5 provisional: Availability 52 / Rarity 48 / やや珍しい / Confidence 0.84

### サゼラック

複数の現行カクテルBARで実提供を確認。クラシックとして現役であり、旧Availability 36はやや低すぎる。

ただしアブサン、ペイショーズビターズ等を常備しない一般BARも多いと考えられ、専門性依存は残す。

v1.5 provisional: Availability 42 / Rarity 58 / 珍しい / Confidence 0.83

### コープスリバイバー No.2

国内の現行BARで提供例を追加確認。存在自体は現役だが、リレ/コキ・アメリカーノ系、アブサン等の材料構成により一般BARでの再現性は低め。

v1.5 provisional: Availability 38 / Rarity 62 / 珍しい / Confidence 0.82

### ラモスジンフィズ

複数の国内BARで現行提供を確認したため、旧Availability 26は「存在の希少性」を強く見過ぎていた。

ただし生クリーム、卵白、柑橘、オレンジフラワーウォーター等に加えて長いシェイク/提供時間が必要で、実店舗自身が「お時間ください」と案内している例もある。したがってOperational Easeの強い減点は維持する。

v1.5 provisional: Availability 32 / Rarity 68 / 珍しい / Confidence 0.84

### ヴューカレ

東京のBARで現行メニュー掲載、大阪のBARでも専門メディア上で提供店を確認。日本で完全に未知のカクテルではない。

一方、ライ、コニャック、スイートベルモット、ベネディクティン、複数ビターズ等を要し、材料常備とクラシック対応力に依存する。

v1.5 provisional: Availability 32 / Rarity 68 / 珍しい / Confidence 0.82

### トリニダードサワー

国内BARのIBA公認カクテルメニューで現行提供を確認。したがって「ほぼ日本では成立しない」扱いまでは下げない。

ただしアンゴスチュラビターズをベース級に大量使用し、オルジェーやライウイスキーも必要という非常に特徴的な構成で、一般BAR標準からは明確に離れる。

v1.5 provisional: Availability 24 / Rarity 76 / かなり珍しい / Confidence 0.78

## 重要な学び

今回の後半群では「名前の知名度」「専門BARでの実在」「一般BARでその場で成立するか」が大きく分離した。

特にラモスジンフィズのように実提供例が複数あっても作業負荷が高いもの、パローマのように日本での知名度印象より実際の提供範囲が広いもの、ヴューカレのように実在はするが材料セットが専門店寄りなものを同じ軸で扱わないことが重要。

したがって今後も `Availability = 実提供45% + 国内材料流通25% + 日本標準性20% + Operational Ease10%` を維持する。
