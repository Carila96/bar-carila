# BarCarila 日本BAR希少度 v1.6 addendum

Status: PROVISIONAL
Date: 2026-09-04
Scope: 現行50杯に25杯を追加し、代表75杯へ拡張するための調査・暫定スコア。
Runtime policy: `japan_rarity_score = 100 - japan_availability_score`。世界的知名度ではなく、日本国内の一般的なBARで実際に注文成立しやすいかを優先する。

## 評価方針

既存v1系の重みを継続する。

- 45%: 日本国内の現行BAR/ホテルBAR等の実メニュー提供確認
- 25%: 国内での材料・ブランド流通、材料の一般性
- 20%: 日本のバーテンダー文化・スタンダード性
- 10%: オペレーション容易性

単一店舗への掲載だけで全国的な定番とは判定しない。逆に、一般ダイニングBAR・ショットBAR・クラシックBAR・ホテルBARなど異なる業態で複数確認できる場合は一般成立性を上げる。

『カクテル完全バイブル』（渡邉一也監修）は日本側のカクテル体系・スタンダード性・材料構成を見る補助資料として使用する。同書は約400種を掲載しているため、単なる掲載だけでは日本BARでの高availabilityの根拠にしない。特に「スタンダード・カクテル24」は掲載一般より強い正の証拠として扱う。

## v1.6での判断

今回の25杯は「世界的なクラシック」だけではなく、日本の一般BARで現実に注文しやすいリキュール系・ワイン系を意図的に追加した。これにより、BarCarilaがクラシックBAR寄りの知識だけに偏るのを防ぐ。

特にカシスオレンジ、ファジーネーブル、スプモーニ、チャイナブルーは、日本の実店舗メニュー密度が高く、世界的なクラシック性とは別軸で日本availabilityを高く置くべき代表例。

一方、アビエーション、B-52は名前自体が知られていても特殊材料・技法または一般メニュー密度の低さがあり、希少度を高めに維持する。
