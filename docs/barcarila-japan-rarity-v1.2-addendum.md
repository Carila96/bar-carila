# BarCarila 日本BAR希少度 キャリブレーション追補 v1.2

Status: PROVISIONAL
Date: 2026-09-04

## 目的

v1.1 の代表50杯データのうち、希少度30〜55%付近の中間帯を重点的に再確認する。ここは「知名度はあるが、実際に日本の一般BARで成立するか」が分かれやすく、BarCarilaの体感品質に直結する。

## 今回の追加確認

### ロングアイランドアイスティー

Suntory BAR-NAVI の現行検索では7店舗がヒットし、shot bar EVER、BAR MOONSHINE 等で実メニュー掲載を確認できる。材料数は多いが、少なくとも日本の一般ショットバーで実際に提供されているため、単純な“珍しい”側へ寄せすぎない。

暫定: Availability 58 / Rarity 42 / やや珍しい / Confidence 0.84

### アメリカーノ

BAR-NAVI の一般BARで実メニュー掲載を確認。カンパリ＋スイートベルモット＋ソーダという材料構成自体も一般BARで成立しやすい。これまでの Availability 38 は低すぎる可能性が高い。

暫定改定: Availability 60 / Rarity 40 / やや珍しい / Confidence 0.82

### ミントジュレップ

Suntory BAR-NAVI で「ミントジュレップ」検索が12店舗ヒット。メーカーズマークの国内BAR向けコンテンツでも明確に取り上げられ、実店舗メニューでも確認できる。生ミント依存は残るが、旧 Availability 48 はやや低すぎる。

暫定改定: Availability 58 / Rarity 42 / やや珍しい / Confidence 0.84

### グラスホッパー

BAR-NAVI で検索26店舗。一般ショットバー/カクテルバーでの存在感が確認でき、材料もクレーム・ド・ミント、カカオ系、クリーム等で特殊すぎない。旧 Availability 55 は概ね妥当だが、やや上方余地。

暫定: Availability 58 / Rarity 42 / やや珍しい / Confidence 0.82

### フレンチ75

東京のBrasserie & Barの現行メニューで提供を確認。シャンパン/スパークリング常備店では成立しやすい一方、一般ショットバー全体では必ずしも普遍的ではない。

暫定維持: Availability 65 / Rarity 35 / やや珍しい / Confidence 0.83

## 今回見えた補正ルール

- BAR-NAVI の検索ヒット数は補助指標であり、母集団全体の普及率としては扱わない。
- ただし、複数の一般ショットバー・カクテルバーで実メニュー掲載が確認できた場合、専門店限定扱いにはしない。
- ホテル/レストランのみで確認できる場合は、日本一般BAR普及度を過大評価しない。
- 材料が一般的でも、名称注文頻度が低ければ Availability を無条件に高くしない。
- 逆に、名称はややクラシックでも、一般BARで材料・技法とも成立しやすい場合は過度に“珍しい”へ寄せない。

## 文章生成の保存方針

BarCarilaの推薦カード文言は、すべて毎回AIにゼロから生成させる必要はない。

### D1に保存してよい固定/準固定テキスト

- `short_description`: 酒自体の短い説明
- `rarity_reason`: 日本BAR希少度の短い理由
- `order_hint`: 店で頼む際の注意や言い換え
- `origin_summary`: 由来/文化背景の短い説明
- `taste_summary`: 基本的な味わい

これらは酒ごとにほぼ不変なので、D1の酒マスターに保存する。表示時に毎回LLMへ生成させない。

### AIに残すべき可変テキスト

- ユーザーの回答を受けた「なぜ今この一杯を選んだか」
- 会話文脈に合わせた一言
- 好み・気分・強さ・甘さ等との接続

ここは個人ごとに変わるためAI生成を維持する。

### 推奨構造

固定情報はD1、推薦理由だけAI。

例:

- D1: 「アペロール、スパークリングワイン、ソーダを使うイタリア生まれの食前酒。日本ではイタリアンやホテルバーで見かけやすい一方、一般BARの定番まではいかない。」
- AI: 「今日は軽くて苦甘いものをゆっくり飲みたいとのことだったので、アペロールスプリッツを選びました。」

この分離により、出力の安定性を上げ、LLMトークン使用量を削減できる。推薦そのものにLLMを使う設計を維持しても、酒の基礎説明を毎回生成する必要はない。
