# CURRENT_TASK

## Task
バーテンダーCarilaのRealtime音声会話を、実機フィードバックに合わせて日本語・導入UX・ログ表示・声質の面で改善する。

## Acceptance criteria
- 音声会話開始直後に「いらっしゃいませ。今日はどういたしますか？」と日本語で定型挨拶する。
- その後はユーザーの実発話にだけ反応する。
- 原則として日本語で会話し、勝手に英語へ切り替わらない。
- 音声会話ボタンを小さくして右寄せする。
- ボタン直下に「お酒を注文する / 少し話したくて / 特に決めていません」の選択肢を表示する。
- 音声会話中でも選択肢をタップするとRealtime会話へ入力できる。
- ボタン下部にユーザーとCarilaの音声文字起こしログを表示する。
- Carilaが話している途中の割り込み会話を維持する。
- 既存テキスト会話と1500杯ドリンクマスター経路を壊さない。
- Realtimeで利用可能な組み込みvoiceの範囲で、現在より男性寄り・低めの暫定voiceを使う。
